# Duel Data Dashboard

デュエルリンクスのランク戦の戦績を記録・可視化し、勝率を **Deck / Tech / Luck** に要因分解するツールです。
ブラウザだけで動き、インストールやアカウント登録は不要です。

## 使い方

1. ページを開き、上部で「使用デッキ」と構築バージョンを選びます。
2. 左（スマホでは Input タブ）の入力欄で、相手デッキ・先後・勝敗などを記録します。
3. 本番の1戦目では「順位・銀ライン・DP・日時」を開き、試合後の実際の DP を入れておくと、以降の DP が正しく計算されます。

スマホでは、ブラウザの「ホーム画面に追加」をしてから使ってください（iPhone では、追加しないと一定期間使わなかったときに記録が消えることがあります）。

## 画面

| タブ            | 内容                                                                           |
| --------------- | ------------------------------------------------------------------------------ |
| Trend（調子）   | DP 推移・移動平均・銀ライン・ボリンジャーバンド・MACD、連続プレイと勝率        |
| Meta（環境）    | 直近10戦の相手デッキの推移、順位帯ごとの相手デッキ、相手デッキ別の勝率         |
| DTL（要因分解） | 勝率 − 50% を Deck・Tech・Luck に分解。ベンチマークの入力                      |
| Odds（確率）    | 初手確率（A・AかB・AとB を引ける確率）、確率の推移グラフ、事故率の理論値の反映 |
| Log（戦績）     | 先後・事故・プレミ、バージョン別の戦績、全記録の一覧                           |
| Setup（設定）   | デッキ・キャラ候補、バックアップ、保存先                                       |

## データの保存

- 記録は、開いた端末のブラウザ（localStorage）に保存されます。サーバーには送信されません。
- PC の Chrome / Edge では、Setup タブで保存先のファイルを選ぶと、記録のたびにそのファイルへ自動保存されます。
- 端末を移るときや念のための控えには、Setup タブの「JSONで書き出し」「JSONから読み込み」を使ってください。

## DTL 要因分解

| 項目     | 式                        | 意味                                                                  |
| -------- | ------------------------- | --------------------------------------------------------------------- |
| **Deck** | Σ s·q − ½                 | デッキタイプの選択による効果                                          |
| 基礎力   | ω自分 − ½                 | デッキの地力（環境全体での勝率）                                      |
| 環境強度 | Σ s(q̂ − ω自分)            | 当たった相手の強さ                                                    |
| メタ相性 | Σ s·γ                     | 多い相手に、強さから見込める以上に勝てたか                            |
| **Tech** | (p̄ − ½) − Deck − Luck     | 他勝率 q との差                                                       |
| 構築力   | Σ s(p − p通常)            | 構築フラグのある試合による勝率の上振れ                                |
| プレイ力 | Tech − 構築力             | 構築以外の腕の差                                                      |
| **Luck** | 先後 + 事故               | 運による効果                                                          |
| 先後     | Σ s(f − ½)(pᶠ − pˢ)       | 先攻を引いた偏り                                                      |
| 事故     | Σ s(a − ā)(x事故 − x通常) | 事故率の、基準 ā からのずれ（ā は Odds タブの理論値、未設定なら実績） |

s：実シェア、q：他勝率（自分と同じデッキを使う他のプレイヤーの、その対面での勝率）、ω：環境勝率、q̂ = σ(logit ω自分 − logit ω相手)、γ = q − q̂。
詳細はアプリの DTL タブ末尾の備考を参照してください。
ベンチマーク（参照シェア・環境勝率・他勝率）の初期値には、PKC の結果を使用しています。

## 開発

ビルド不要の静的サイトです。

```
index.html        画面の構造
assets/style.css  見た目（色はすべて :root のトークンで定義）
assets/app.js     動作（集計・グラフ描画・DTL 計算）
```

`index.html` をブラウザで開けば動きます。GitHub Pages などの静的ホスティングにそのまま置けます。
